Procedimento Fluxo de Trabalho
Seis etapas para um inventário municipal completo
Fase 1
Dados de Atividade
Levantamento da frota circulante, contagens de tráfego, dados GPS, modelos de demanda de viagens, pesquisas origem-destino.
Frota por tipo/ano/combustível
Contagens volumétricas
Dados de quilometragem
Fase 2
Fatores de Emissão
Aplicação de fatores validados para a realidade brasileira — etanol, biodiesel, flex-fuel. Fontes: CETESB, dados de inspeção veicular, literatura.
Poluentes: CO, NOx, HC, PM, CO₂
Evaporativas + escape
Partida fria
Fase 3
Espacialização
Distribuição geográfica das emissões com resolução de via — perfis horários de tráfego, dados de GPS, malha viária municipal.
Emissões por rua
Perfis diários/semanais
Mapas de calor de poluentes
Fase 4
Validação
Comparação com dados de monitoramento da qualidade do ar, túneis, e estudos anteriores. Ajuste iterativo dos fatores.
Dados de estações
Campanhas de túnel
Benchmarking
Fase 5
Modelagem
Exportação para modelos de qualidade do ar (WRF-Chem, MUSICA) via eixport e EmissV. Cenários de curto e longo prazo.
WRF-Chem · MUSICA · CAMx
Formato GRADS · netCDF
Fase 6
Cenários
Simulação de políticas públicas: renovação de frota, etanol vs gasolina, restrições veiculares, eletrificação, Zonas de Baixa Emissão.
PROCONVE · Renovação
Eletrificação · Biocombustíveis

Inventário Completo
Base de emissões veiculares com resolução de via e horária. CO, NOx, HC, PM₂.₅, PM₁₀, CO₂ — totais municipais e por bairro.
Modelo replicável anualmente
🗺
Dashboard Interativo
Mapas de calor de emissões, séries temporais, comparação entre cenários. Visualização acessível para tomadores de decisão.
Dados abertos · formato padronizado
🎯
Cenários de Política
Avaliação quantitativa de intervenções: expansão do etanol, renovação da frota, pedágio urbano, Zona de Baixa Emissão, eletrificação de táxis e ônibus.
Base para tomada de decisão
